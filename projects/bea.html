Software Development Internship · Banque Extérieure d'Algérie

Credit Management Decision-Support System

Development of a software system to support credit-management decisions using financial rules and customer profile criteria.

Project Overview

During my software development internship at Banque Extérieure d'Algérie (BEA), I worked on a decision-support application for credit management.

The system was designed to organize customer information and apply business and financial criteria to support credit-related decisions.

Focus: Software development, business rules, database integration and decision support.
Java NetBeans SQL UML Decision Support Business Rules

The Business Problem

Credit-management decisions depend on multiple pieces of customer information and financial criteria.

The objective was to create a software solution that could structure this information and apply predefined decision rules in a consistent way.

Technical Solution

Application Development

The application was developed in Java using the NetBeans development environment.

Business Rules

Financial rules and customer-profile criteria were incorporated into the decision-support logic used by the application.

Database Integration

Customer and credit-related information was managed through database integration using SQL.

System Design

UML modeling was used to structure and communicate the design of the application.

My Contribution

  • Developed functionality using Java.
  • Worked with customer and financial information.
  • Implemented business rules for decision support.
  • Integrated application logic with database operations.
  • Used UML to structure the software design.
  • Tested the application's decision-support functionality.

Outcome

The project demonstrated how software engineering can be used to translate financial business rules into a structured decision-support application.

It also gave me practical experience in Java development, database integration and developing software around real-world business requirements.
