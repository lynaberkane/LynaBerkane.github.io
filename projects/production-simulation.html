Production System Simulation

Discrete-event simulation of a production environment to analyze capacity, bottlenecks and the impact of different production scenarios.

Project Overview

This project focused on modeling and simulating a production system using AnyLogic. The objective was to understand how production parameters influence system performance and to support decisions through simulation-based analysis.

Goal: Analyze production performance and compare different operational scenarios before making physical changes to the production system.
AnyLogic Discrete-Event Simulation Production Systems Process Analysis Scenario Analysis

Business Problem

Production systems can experience bottlenecks, queues and capacity constraints when product mix and processing times change.

The challenge was to create a simulation model that could represent the production process and allow different operational scenarios to be tested.

Simulation Approach

Production Model

A production environment based on a German packaging case was modeled using discrete-event simulation.

Different setup times were considered depending on the product or product family.

Demand

Orders were introduced using a 2024 demand scenario to analyze how the production system responds to the expected workload.

What I Analyzed

  • Production capacity and throughput.
  • Potential bottlenecks in the production flow.
  • Queues and waiting times.
  • Resource utilization.
  • Impact of setup times on production performance.
  • Different equipment and material-flow scenarios.

Investment Scenarios

The simulation also considered different material-handling options and their associated investment costs.

  • 5 trolleys at approximately €800 each.
  • 3 AMRs at approximately €35,000 each.
  • 1 conveyor system at approximately €150,000.

These scenarios provided a basis for comparing operational performance with potential investment requirements.

Outcome

The simulation provided a structured way to test production scenarios and understand how operational parameters affect system performance.

Rather than relying only on assumptions, the model can be used to compare alternatives and identify potential bottlenecks before implementing changes in a real production environment.
