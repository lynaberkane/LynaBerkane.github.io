Ergonomic Analysis Using Wearable Sensors

Analysis of body movement and ergonomic strain using wearable sensor data collected with an IMU-based system.

Project Overview

This project explored how wearable sensor data can be used to analyze ergonomic conditions during repetitive tasks.

An IMU-based sensor system was used to collect movement data while participants performed a LEGO assembly task in different working positions.

Focus: IoT sensors, data acquisition, Python data processing and ergonomic analysis.
Python Arduino BNO085 Sensor Data IoT Ergonomics

Research Question

The project investigated how different working positions influence ergonomic strain during a repetitive assembly task.

Two conditions were compared: performing the task while sitting and performing it while standing.

Data Collection

A BNO085 inertial measurement unit (IMU) connected to an Arduino was used to collect sensor measurements.

The collected data was exported and processed using Python for further analysis.

The study included measurements from 9 participants.

Analysis

Working Position Comparison

The sensor data was analyzed to compare the measured task performance and ergonomic strain between sitting and standing conditions.

833.88 s Sitting task time
861.64 s Standing task time
26.81% Non-ergonomic strain — sitting
11.05% Non-ergonomic strain — standing
